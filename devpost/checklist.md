# Japanese Learning App — Build Checklist

Build mode: fast — chosen by the learner on 2026-10-13. Verify and commit every slice; pause for the planned early, spoken/offline and final hands-on checkpoints, with shorter explanations between them.

This implements the approved scope, PRD, and revised technical spec. Android is the learning app; Next.js is a landing page only. The same complete MVP serves both events. No coding-hour estimates or reduced event-specific milestone are used.

The learning kernel appears in slice 2, immediately after account/setup. Every slice adds usable behavior across the required layers and retains what earlier slices delivered. Live-service checks must use actual authorized access: missing credentials, exhausted quotas, or unsupported models are reported as incomplete, never replaced with a simulated integration claim. Pure-function and synthetic-fixture tests supplement real-device/provider checks.
